# E-Commerce Sales Data Analysis

## Project Overview

This project analyzes an e-commerce sales dataset using Python to identify sales trends, profit patterns, and product performance.

The analysis uses Pandas and NumPy for data processing and Matplotlib for data visualization. The results are presented through charts and business insights to help understand the company's sales and profitability.

## Key Business Insights

1. Category Performance: Technology generated the highest sales ($836,154.03) and profit ($145,454.95) among the three product categories.

2. Regional Performance: The West region recorded the highest sales ($725,457.82) and profit ($108,418.45).

3. Yearly Sales Trend: Sales increased from $470,532.51 in 2015 to $733,215.26 in 2017.

4. Monthly Sales Trend: November recorded the highest total sales, while February recorded the lowest, when combining data across all years.

5. Top Product by Sales: Canon imageCLASS 2200 Advanced Copier recorded the highest total product sales ($61,599.82).

6. Top Product by Profit: Canon imageCLASS 2200 Advanced Copier also generated the highest product profit ($25,199.93).

7. Sub-Category Profitability: Copiers generated the highest total profit ($55,617.82), while Tables recorded the largest loss (-$17,725.48).

8. Profit Margin: Technology had the highest category profit margin (17.40%), while Furniture had the lowest (2.49%).


## Project Objectives

- Analyze the e-commerce dataset using Python.
- Inspect the dataset for missing values, duplicate records, and data types.
- Calculate total sales, total profit, and average sales and profit.
- Compare sales and profit across product categories and regions.
- Identify yearly and monthly sales trends.
- Identify the top 10 products by sales and profit.
- Analyze profitability at the product sub-category level.
- Calculate and compare profit margins across categories.
- Create visualizations to communicate business findings.


## Tools and Libraries Used

- Python: Used to write and execute the analysis code.
- Pandas: Used to load, clean, group, and analyze the dataset.
- NumPy: Used for numerical computing.
- Matplotlib: Used to create charts and visualizations.
- Visual Studio Code (VS Code): Used as the development environment.
- Git: Used for version control.
- GitHub: Used to publish and share the project repository.

## Dataset Description

The project uses an e-commerce sales dataset containing information about customer orders, products, sales, profit, shipping dates, regions, and product categories.
The dataset includes fields such as Order Date, Ship Date, Category, Sub-Category, Product Name, Sales, Profit, and Region.

## Visualizations
This project includes 12 charts created using Matplotlib to analyze monthly and yearly sales, sales and profit by category and region, top-performing products, sub-category performance, and profit margins.

## How to Run the Project

### Prerequisites

- Python 3 installed
- Visual Studio Code or another Python editor
- Git (optional, for version control)

### Installation

1. Clone or download this repository.

2. Open the project folder in your terminal.

3. Install the required libraries:
   
   pip install -r requirements.txt

### Run the Project

Execute the following command from the project root directory:

python main.py

The analysis results will be displayed in the terminal, and the charts will be saved in the "outputs" folder.
